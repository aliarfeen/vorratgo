# VorratGo 🛒  
**VorratGo** is a modern, sleek, and scalable eCommerce mobile application built using **Flutter**. Designed for speed, performance, and great user experience, VorratGo enables users to browse categories, discover offers, search products, and manage carts efficiently.

---

## 📱 Features  

- 🛍️ **Product Catalog** – View products organized into categories  
- 🎯 **Featured Offers** – Showcase deals and discounts dynamically  
- 🔍 **Powerful Search** – Find products quickly using search with filters  
- 🛒 **Cart Management** – Add, remove, and edit cart items with real-time updates  
- 💳 **Checkout Flow** – Streamlined order placement (UI only)  
- 🌐 **API Integration Ready** – Easily connect your backend via RESTful APIs  
- 🔐 **Authentication** – Firebase Email/Password login and registration  
- 👤 **User Profile** – Fetch and display user data from Firestore  
- 🚪 **Guest Access Mode** – Option to enter the app without login  

---

## 🚀 Tech Stack  

- **Flutter** – Frontend framework  
- **Dart** – Primary programming language  
- **BLoC / Cubit** – State management pattern  
- **Dio** – HTTP client for API calls  
- **Firebase Auth** – Authentication (Email & Password)  
- **Cloud Firestore** – Realtime database for user and product data  
- **Dependency Injection (GetIt)** – For managing repositories and cubits cleanly  
- **Shared Preferences** – For local data caching and user session persistence  
- **Clean Architecture Principles** – Layered design (Data ➜ Domain ➜ Presentation)  

---

## 🧠 Skills Being Applied  

- Advanced **state management** using Cubits & BLoC  
- **Dependency Injection** setup for scalable architecture  
- Handling **Firebase Auth** and **Firestore** integration  
- Building **modular feature-based folders** for better code organization  
- Using **Repository pattern** to separate data sources (Remote & Local)  
- Applying **form validation**, error handling, and observers for debugging
